# V1.6.3 实现计划：复核改级后同步修订对外叙述

> 版本：V1.6.3 | 日期：2026-08-12 | 设计：[v1.6.3-design.md](v1.6.3-design.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 复核节点改动 HABC 等级时，同步修订 `analysis_text` 第五段与 `lead_summary`，消除对外叙述与最终等级自相矛盾。

**Architecture:** 定级 Prompt 为 `analysis_text` 五段加固定中文标题，使第五段可被代码确定性定位；复核 Prompt 在改级时额外输出 `revised_conclusion`（不含标题的正文）与 `revised_lead_summary`；pipeline 用纯函数 `_revise_analysis` 按锚点 `五、总体评价` 做 `rfind` 切分替换，前四段逐字保留；锚点缺失则退化为文末追加，全程 fail-open。新增审计字段 `analysis_revision` 暴露锚点命中率。

**Tech Stack:** Python 3.14 / Pydantic v2 / SQLAlchemy / pytest（`pytest-asyncio`，`asyncio_mode=auto`）/ 自研 Skill 执行器（`string.Template` 渲染 Prompt）

## Global Constraints

- 对外 API 契约不变：`ProfileResult.analysis`、`profile_summary` 等字段类型与语义不动；新增字段一律为内部审计字段。
- 历史落库数据不回填、不清洗。
- 所有 Prompt 与文档一律简体中文；JSON 字段名、枚举字面量、布尔值、`$占位符` 保留英文不译。
- Prompt 文件写入后必须校验无 U+FFFD 乱码（项目有 UTF-8 写入踩坑史，见 commit `086466e`）。
- 旧 Prompt 文件保留不动、不再被引用（VERSIONING.md 第 4 节）。
- 版本号三处必须同步：Skill YAML `version`、YAML `prompt_file`/`prompt_version`、`pipeline.py` 的 `SKILL_VERSIONS`。`tests/test_agent2.py` 有一致性断言防止只改一处。
- fail-open 语义不得削弱：复核链路任何异常都必须保留初步等级与初步文本，绝不使整个用户分析任务失败。
- Windows 控制台是 GBK，`python -c "print(中文)"` 会显示乱码。校验文件内容一律用 `pathlib.read_text(encoding="utf-8")` 后断言布尔值，不要直接打印中文。

```python
# V1.6.3：analysis_text 第五段的定位锚点，须与定级 Prompt
# （user_lead_analysis_v1.6.3.txt）中的第五个段标题逐字一致。
CONCLUSION_ANCHOR = "五、总体评价"


def _revise_analysis(analysis_text: str,
                     revised_conclusion: str | None) -> tuple[str, str]:
    """用复核给出的新结论替换 analysis_text 的第五段"总体评价"。

    返回 (新 analysis_text, analysis_revision)。纯函数，不抛异常。
    前四段是与等级无关的事实陈述，必须逐字保留——把"原样照抄"交给模型
    做不可靠，只有代码切分能兑现这一点。锚点缺失时退化为文末追加，
    宁可效果打折也绝不失败。
    """
    body = (revised_conclusion or "").strip()
    if not body:
        return analysis_text, "none"
    # 模型可能不听话地把段标题也写进正文，剥掉避免重复标题
    if body.startswith(CONCLUSION_ANCHOR):
        body = body[len(CONCLUSION_ANCHOR):].lstrip("：: \t\n")
    text = analysis_text or ""
    # 总体评价是末段：用最后一次出现，避开前文对该标题的引用
    idx = text.rfind(CONCLUSION_ANCHOR)
    if idx >= 0:
        return f"{text[:idx]}{CONCLUSION_ANCHOR}\n{body}", "replaced"
    sep = "\n\n" if text else ""
    return f"{text}{sep}{CONCLUSION_ANCHOR}（复核修订）\n{body}", "appended"
```
