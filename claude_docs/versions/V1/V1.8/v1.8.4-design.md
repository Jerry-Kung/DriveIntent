# V1.8.4 设计：定级 Prompt 第四段禁止等级性结论

> 版本：V1.8.4 | 日期：2026-09-02

## 1. 背景

2026-09-02 排查作业 `b4df87e0-2da1-4926-9e68-8a1a05ddd967`（账号
`MS4wLjABAAAA-pdCg57...`，昵称"锐驰工贸"）时发现：对外定级结果为 **C（low）**，
但 `analysis` 文本第四段"主页画像与调整结论"写着"因此，最终评级维持B级"，
第五段却已是 C 级论证——**定级与分析文本矛盾**。

### 1.1 证据链

1. 定级节点输出 `baseline_grade=B`、`profile_adjustment=none`（无画像上调证据）、
   `lead_grade=B`；`analysis_text` 第四段写"最终评级维持B级"。
2. 普通复核节点 `review_action=downgraded`、`reviewed_grade=C`，给出了
   `revised_conclusion`（新"总体评价"正文）。
3. `_run_review` 走 V1.6.3 锚点修订：按 `CONCLUSION_ANCHOR`（"五、总体评价"）
   **只替换第五段**，前四段逐字保留 -> 第四段"维持B级"残留。
4. `apply_polish` 因 `out.lead_grade == "C"` 直接短路（V1.7.0 省成本决策，
   最终无价值线索一律不润色），第四段矛盾无人修复。

### 1.2 根因

V1.6.3 设计假定"`analysis_text` 五段中仅第五段与 HABC 绑定，前四段是事实
陈述，与等级无关"。该假定在第四段"主页画像与阶段三调整结论"上**不成立**：
第四段标题本身即邀请模型在段末输出等级性结论（"最终评级维持/调整为 X 级"）。
B 经复核降级到 C 时，这类等级句随前四段逐字保留，形成矛盾。V1.8.0（阶段二
不再调级）未同步修正此假定。

非代码逻辑 bug——复核降级、锚点替换、润色短路都是既有预期行为；缺的是
在**源头 Prompt** 上约束第四段不输出等级性结论。

## 2. 改动

### 2.1 Prompt：`user_lead_analysis` v1.8.4（唯一实质改动）

`analysis_text` 段说明中第四段"主页画像与阶段三调整结论"的内容要求收紧为：
只陈述主页画像事实、是否命中画像上调的直接证据（含经阶段三验证后基线评级
发生的变化），**不得在本段输出任何等级性结论**（例如"最终评级维持/调整为
X 级"）；等级结论统归第五段"总体评价"，且第五段明确写出最终等级 X 级。

五段标题、其余四段内容要求、三阶段流水线、可读性禁令等一概不动。

### 2.2 版本级联

- `app/skills/analysis_polish.py` / `app/skills/user_review.py`：段标题一致性
  注释引用的 prompt 文件名由 v1.6.3 改为 v1.8.4（纯注释，非逻辑）。
- `tests/test_agent2.py`：`SKILL_VERSIONS` 与 config/prompt_version 断言升至
  1.8.4；`test_v163_analysis_prompt_has_fixed_section_headings` 补两条
  （第四段禁等级句、等级统归第五段）。
- YAML / `pipeline.py` `SKILL_VERSIONS` / OVERVIEW 能力快照与变更索引。

### 2.3 明确不做

- 不动润色节点对最终 C 的短路（V1.7.0 成本决策，保留）。
- 不扩锚点修订范围到第四段（代码理解语义切分等级句不可靠，违背 V1.6.3
  "代码切分而非模型照抄"原则）。
- 不回填/清洗历史落库数据：存量"B 降 C"样本的第四段残留本次不修复。
- 不改复核/过滤/润色 Prompt、不动对外契约与 DB schema。

## 3. 影响范围

- **对外契约**：无变化。`analysis` 文本质量从源头改善，字段类型与语义不动。
- **存储**：无迁移。仅 Prompt 文本变更，落库结构不变。
- **版本级联**：`user_lead_analysis` 升 1.8.4。V0 聚合按 `SKILL_VERSIONS`
  过滤，升版后 1.8.3 历史定级行不再复用，存量用户会重跑定级（历次升版
  既定模式）；API 路径无历史复用问题。
- **调用次数**：不变（每账号仍为 过滤+定级+复核+润色 = 4 次，识图另计）。

  "等级结论统归第五段"。
- 联调观察项：后续"初评 B 经复核降级到 C"样本的 `analysis` 第四段不再出现
