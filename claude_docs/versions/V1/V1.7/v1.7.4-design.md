# V1.7.4 设计：阶段二比对基准定为与目标车型最接近的在售车型

> 版本：V1.7.4 | 日期：2026-08-24

## 1. 背景与问题

Agent2（用户精筛定级）的**阶段二：车型匹配调整**（`user_lead_analysis` Prompt）
依据用户目标车型与我方在售车型的价格区间、车型类别判定四档
（`our_model` / `similar` / `partial` / `unrelated` / `unknown`）。

当前规则只说"与**全部**我方在售车型进行比对"，未规定以哪款车作对比基准。
LLM 可在多款在售车型中任选一款比较，或作笼统判断，容易选错对比车型导致误判。

**典型误判示例**：

- 我方在售：M817（29-39 万越野 SUV）、M917（63-69 万越野 SUV）；
- 用户目标：坦克300（20-30 万硬派越野）；
- 正确基准：应选价格、类别最接近的 **M817** —— 品类同为越野、价位接近 →
  判 `similar`（不调整）或 `our_model`（若直指我方）附近档位；
- 错误基准：若选 **M917** 对比 —— 价格区间相差悬殊 → 易误判为 `unrelated`
  而**错误降级**（如从 B 降两级），损失真实线索。

## 2. 方案

在阶段二开头增加"比对基准"约束：**先用我方在售车型中与用户目标车型最接近的
一款作为主要对比车型**——综合价格区间与车型类别选差距最小者，多款难分伯仲时取
价格更接近者；判定档位与下调均以此款为基准，而非拿全部在售车型逐一比较或任选一款。
同时要求 `match_reason` 写明所选对比车型（型号/价位）及比对依据。

保留四档判定标准、边界规则（C 不参与、下调下限 C、上调上限 H、多目标取最优）与
`unknown` 兜底逻辑不变。

## 4. 契约影响

**对外 API 契约不变**——字段结构、等级代码、审计字段（`model_match_level` /
`match_adjustment` / `match_reason`）均不变，仅 `match_reason` 叙述要求更具体。
本变更只影响阶段二的比对基准选择与定级调档结果。
