# V1.9.2 实现计划：疑似黑名单账号识别

> 版本：V1.9.2 | 日期：2026-09-08
> 设计文档：`claude_docs/versions/V1/V1.9/v1.9.2-design.md`

**Goal**：在"用户精筛定级"的 `user_lead_filter` 节点识别疑似营销号/疑似虚假账号，命中直接定 C 不进定级流程，并把 `is_blacklisted` / `blacklist_type` / `blacklist_reason` 三字段透出对外 API，供前端拉黑异常账号参考。

**Architecture**：复用 `user_lead_filter` 唯一一次 LLM 调用（零新增调用）识别疑似黑名单；确认黑名单（V1.9.0 数据库命中）与疑似黑名单统一三字段口径（type 分别 `"confirmed"` / `"营销号"` / `"虚假账号"`）。

## 任务分解

### Task 1: Schema 三字段
- `app/schemas/skills.py`：`UserFilterResult`（`blacklist_type` Literal 中文两种）、`UserLeadResult`（`blacklist_type` str）加 `is_blacklisted`/`blacklist_type`/`blacklist_reason`。
- `app/api/schemas.py`：`ProfileResult` 加同三字段。
- 测试：`test_user_filter.py` `test_v192_user_filter_result_*` / `test_v192_user_lead_result_blacklist_defaults`。

### Task 2: 过滤节点逻辑
- `app/skills/user_filter.py`：`run_user_filter` 加"`is_blacklisted=true` 缺 `blacklist_type` → fail-open 放行"；`build_filtered_lead_result` 透传三字段，黑名单命中记 `filter_category="blacklist_suspect"`。
- 测试：`test_v19_run_user_filter_malformed_blacklist_fail_open`、`test_v192_run_user_filter_marketing/fake_hit`、`test_v192_build_filtered_lead_result_*`。

### Task 3: Agent2 集成
- `app/api/agent2.py`：确认黑名单短路补三字段（type="confirmed"）；过滤后加 `is_blacklisted` 分支（优先于 `filtered`）直接合成 C；异常兜底补三字段（false/null/null）。
- `app/api/mapping.py`：`map_profile_result` 两分支透传三字段。
- `app/workflow/pipeline.py`：V0 路径 `if filt.is_blacklisted or filt.filtered`。
- 测试：`test_agent2.py` `test_v192_marketing/fake_suspect_short_circuits*`、`test_v192_confirmed_blacklist_carries_three_fields`、`test_v192_normal_account_carries_null_blacklist_fields`、`test_v192_error_item_carries_null_blacklist_fields`；`test_api_mapping.py` `test_map_profile_carries_blacklist_fields` 等。

### Task 4: Prompt 升版
- 新增 `app/skills/prompts/user_lead_filter_v1.9.2.txt`（含疑似黑名单规则 + 三字段输出），删除 `user_lead_filter_v1.6.1.txt`。
- `app/skills/configs/user_lead_filter.yaml`：`version="1.9.2"`、`prompt_file="user_lead_filter_v1.9.2.txt"`、`prompt_version="v1.9.2"`。
- 测试（改基线）：`test_user_filter.py` 的 `test_v16_filter_config` 版本断言、`test_v161_filter_prompt_readability_ban` 换行子串；新增 `test_v192_filter_prompt_has_blacklist_rules`。
