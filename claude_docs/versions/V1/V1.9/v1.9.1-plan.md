### Task 1: 服务层扩展（list_blacklist 分页/搜索 + count_blacklist）

**Files:**
- Modify: `app/services/blacklist.py`
- Test: `tests/test_blacklist_service.py`（追加）

**Interfaces:**
- `list_blacklist(session, *, search=None, offset=None, limit=None)`：三参数缺省 `None` → 行为与现状完全一致（全量倒序）。`search` 非空时 `Where(or_(douyin_id.like, nickname.like, remark.like))`（`%q%`，NULL 列不命中）；`offset`/`limit` 非空时加 `offset/limit`。
- `count_blacklist(session, *, search=None) -> int`：同条件 `func.count`；`search` 缺省时全量 count。
- `like` pattern 要转义 `%`/`_`（防用户输入含 LIKE 通配符导致意外宽匹配）；用 SQLAlchemy `func.concat('%', q, '%')` 或手工 `f"%{esc}%"`。

### Task 2: 对外黑名单 API 路由

**Files:**
- Create: `app/api/blacklist.py`
- Modify: `app/main.py`（`app.include_router(blacklist_api_router)`）
- Test: `tests/test_api_blacklist.py`（新建）

**Interfaces:**
- `blacklist_api_router = APIRouter()`，三条路由均 `dependencies=[Depends(require_api_key)]`：
  - `GET /api/v1/blacklist`（`page`/`page_size`/`q`）：归一化（page<1→1，page_size>100→100），调 `count_blacklist` + `list_blacklist`，返回 `{items:[{blacklist_id, douyin_id, nickname, remark, created_at}], total, page, page_size}`；`created_at` 转东八区 ISO 8601（复用 `routes.py` 的 `_TZ8` 逻辑）。
  - `POST /api/v1/blacklist`：请求 `{douyin_ids, nickname?, remark?}`；`douyin_ids` 空数组 → `422`；调 `add_blacklist`，返回 `{added, skipped, invalid}`。
  - `DELETE /api/v1/blacklist/{blacklist_id}`：调 `delete_blacklist`；命中 `204`，未命中 `404 {"detail": "黑名单记录不存在"}`。
- 复用 `app.api.routes` 的 `get_db`/`require_api_key`（不复制）。

- [ ] 先写失败测试：GET 分页/倒序/`q` 搜索/`total`；page/page_size 归一化；POST 新增/重复跳过/非法计数/空数组 422/nickname·remark 生效；DELETE 204/404；无/错 key → 401；中文 nickname/remark 往返无乱码
- [ ] 实现路由 + `main.py` 注册
- [ ] `pytest tests/test_api_blacklist.py -q` 通过；既有 `test_web_blacklist.py`、`test_api_routes.py` 不回归
